# Screenshots Guide for Chrome Web Store

High-quality screenshots are crucial for getting users to install your extension. This guide will help you create professional screenshots.

## Requirements

**Chrome Web Store Screenshot Requirements:**
- **Minimum size:** 640x400 pixels
- **Maximum size:** 3840x2400 pixels
- **Recommended:** 1280x800 pixels (best quality/size ratio)
- **Format:** PNG or JPEG
- **File size:** Under 2MB each
- **Number:** Minimum 1, maximum 5

## Tools for Creating Screenshots

### Windows
- **Snipping Tool** (built-in)
  - Press `Win + Shift + S`
  - Select area
  - Paste in image editor

- **Greenshot** (free)
  - Better annotation features
  - Download: https://getgreenshot.org/

- **ShareX** (free, advanced)
  - Screenshot + editing + upload
  - Download: https://getsharex.com/

### Mac
- **Built-in Screenshot**
  - Press `Cmd + Shift + 4`
  - Drag to select area

- **Cleanshot X** (paid, professional)
  - Best for professional screenshots
  - Website: https://cleanshot.com/

### Linux
- **Flameshot** (free)
  - Good annotation features
  - Install: `sudo apt install flameshot`

- **Shutter** (free)
  - Feature-rich
  - Install: `sudo apt install shutter`

### Best Practices

**DO:**
- ✅ Use actual ChatGPT interface
- ✅ Show real conversations (blur sensitive content if needed)
- ✅ Make buttons clearly visible
- ✅ Use high resolution (1280x800)
- ✅ Ensure good contrast
- ✅ Add subtle annotations to highlight features
- ✅ Show the extension in use
- ✅ Use professional-looking annotations

**DON'T:**
- ❌ Use fake/mocked screenshots
- ❌ Show incomplete or broken UI
- ❌ Include personal information

- ❌ Use low resolution
- ❌ Add too many annotations (cluttered)
- ❌ Show error messages
- ❌ Include browser UI that's not relevant

## Step-by-Step: Creating Screenshot 1

### Method 1: Simple (No Annotations)

1. **Setup:**
   - Open Chrome
   - Go to ChatGPT
   - Load a conversation with 5+ messages
   - Make sure extension is loaded

2. **Prepare the view:**
   - Zoom to 100% (Ctrl+0 or Cmd+0)
   - Scroll so buttons are visible in bottom-right
   - Make sure no overlapping elements

3. **Take screenshot:**
   - Windows: `Win + Shift + S`, select area
   - Mac: `Cmd + Shift + 4`, drag to select
   - Capture the main content area (not entire screen)

4. **Crop and resize:**
   - Open in image editor
   - Crop to 1280x800 or maintain 16:10 ratio
   - Save as PNG

### Method 2: With Annotations (Better)

1. **Take base screenshot** (follow Method 1)

2. **Open in editor:**
   - Open screenshot in Paint.NET, GIMP, or Photoshop

3. **Add red circle:**
   - Use ellipse tool
   - Draw circle around navigation buttons
   - Make it red (#FF0000)
   - 3-5px stroke width
   - No fill (transparent)

4. **Add arrow (optional):**
   - Use line or arrow tool
   - Draw from circle to a text label
   - Same red color

5. **Add text label (optional):**
   ```
   Navigation Buttons
   Click to jump between messages
   ```
   - Use clear, readable font
   - Size: 24-32px
   - Color: White with black shadow, or black with white background

6. **Save:**
   - Save as PNG
   - Name it: `screenshot-1-main-feature.png`

- [ ] Buttons are clearly visible

- [ ] Good contrast and readability

## Example Screenshot Workflow

1. **Morning:** Install extension fresh, clear browsing data
2. **Setup:** Create a good test conversation in ChatGPT
3. **Screenshot 1:** Basic view with buttons visible
4. **Screenshot 2:** Add annotations showing keyboard shortcuts
5. **Screenshot 3:** Show dark mode version
6. **Edit:** Polish all screenshots
7. **Review:** Check all are 1280x800, under 2MB
8. **Upload:** Add to Chrome Web Store listing with captions

## Pro Tips

1. **Use a clean browser profile** - No other extensions visible
2. **Disable unnecessary browser elements** - Hide bookmarks bar
3. **Use consistent zoom level** - Always 100%
4. **Take multiple shots** - Choose the best one
5. **Show variety** - Different conversations, themes
6. **Tell a story** - Screenshots should flow logically
7. **Keep it simple** - Don't over-annotate

## Common Mistakes to Avoid

- ❌ Screenshots too small (640x400 is minimum, but looks bad)
- ❌ Buttons not visible or cut off
- ❌ Personal conversations visible
- ❌ Too many browser UI elements
- ❌ Inconsistent screenshot sizes
- ❌ Blurry or low quality
- ❌ Wrong aspect ratio (stretched/squashed)
- ❌ No captions provided

## After Creating Screenshots

1. **Name them clearly:**
   ```
   screenshot-1-main-feature.png
   screenshot-2-keyboard-shortcuts.png
   screenshot-3-dark-mode.png
   ```

2. **Store in a screenshots folder:**
   ```
   screenshots/
   ├── screenshot-1-main-feature.png
   ├── screenshot-2-keyboard-shortcuts.png
   └── screenshot-3-dark-mode.png
   ```

3. **Write captions:**
   - Keep captions in STORE_LISTING.md
   - Copy-paste when uploading

4. **Review one more time:**
   - Open each screenshot
   - Verify they look good
   - Check file sizes
   - Ensure quality
