🔧 ChatGPT Quick Switch - Troubleshooting Guide

⚡ Quick Fix - Try This First!

  1. Refresh ChatGPT - Press F5 or Ctrl+R
  2. Hard Refresh - Press Ctrl+Shift+R (clears cache)
  3. Check the URL - Make sure you're on https://chatgpt.com or https://chat.openai.com
  4. Look Bottom-Right - The buttons are in the bottom-right corner, scroll if needed

Step-by-Step Troubleshooting

Step 1: Verify Extension is Loaded

  1. Open Chrome
  2. Go to chrome://extensions/
  3. Find "ChatGPT Quick Switch" in the list
  4. Make sure the toggle is ON (blue)
  5. Look for any error messages under the extension name

✅ The extension card should be blue/active, not grayed out

Step 2: Check Console for Errors

  1. Go to https://chatgpt.com
  2. Press F12 to open Developer Tools
  3. Click the "Console" tab
  4. Look for any red error messages
  5. Look for extension messages (if you see JavaScript errors, take a screenshot)

Debug mode adds helpful console messages like "🚀 Extension loaded!" so you can see exactly what's happening.

Step 3: Verify Files are Present

Make sure these files exist in your chat-jump folder:

  • manifest.json
  • content.js
  • styles.css

Step 4: Test on a Conversation Page

  1. Make sure you're on an actual conversation page, not the home screen
  2. The URL should look like: https://chatgpt.com/c/XXXXX
  3. Make sure there are messages in the conversation
  4. The buttons only appear when there are messages to navigate

Step 5: Reload the Extension

  1. Go to chrome://extensions/
  2. Find your extension
  3. Click the circular reload icon (🔄)
  4. Go back to ChatGPT and refresh the page

Step 6: Try Removing and Re-adding

  1. Go to chrome://extensions/
  2. Click "Remove" on ChatGPT Quick Switch
  3. Close and reopen Chrome
  4. Go back to chrome://extensions/
  5. Enable "Developer mode"
  6. Click "Load unpacked"
  7. Select your chat-jump folder
  8. Go to ChatGPT and test

Common Issues & Solutions

❌ "Could not load manifest"

Problem: Invalid manifest.json

Solution:

  • Run fix-manifest.bat to use the no-icons version
  • OR generate icons using create-icons.html

❌ Extension loads but no buttons appear

Possible causes:

  • Not on the right page (must be chatgpt.com or chat.openai.com)
  • No messages in the conversation yet
  • JavaScript error preventing execution
  • CSS not loading properly

Solution:

  • Enable Debug Mode (button above)
  • Check console for messages
  • Try a hard refresh (Ctrl+Shift+R)

⚠️ Buttons appear but don't work

Solution:

  • Make sure you have multiple messages in the conversation
  • Check if buttons are grayed out (disabled)
  • Try clicking on a message first, then use buttons
  • Check console for errors

Still Not Working?

Collect Debug Information

If nothing above helped, collect this info:

  1. Chrome version: Go to chrome://version/
  2. Console errors: Screenshot of F12 Console tab
  3. Extension page: Screenshot of chrome://extensions/
  4. Files present: Screenshot of folder contents
